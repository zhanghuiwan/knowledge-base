# 网站设计规范

## 网站定位

这是一个纯知识库阅读网站，只服务于两个目的：让用户阅读文章，以及让 AI 能够从仓库中读取文章。不要加入个人介绍、友链、动态、评论、登录或无关的营销内容。

## 页面结构

- 首页：简洁说明这是一个知识库，并突出文章入口。
- 文章列表：展示所有文章标题和简短摘要，不按领域建立文件夹分类。
- 文章页：左侧文章导航，中间正文，右侧当前页面目录（宽屏时显示）。
- 顶部只保留知识库名称、首页/文章入口和搜索。

## 视觉原则

- 以阅读为中心，优先保证清晰、安静、稳定，不追求装饰性效果。
- 使用浅色背景、深色正文和克制的蓝色强调色；同时提供 VitePress 深色模式兼容。
- 正文行宽适中，段落行距舒适，标题层级明确。
- 代码块、公式、表格和 Mermaid 图表必须清晰可读；宽内容允许横向滚动。
- 卡片和边框只用于必要的信息分组，避免大面积渐变、花纹和过度阴影。
- 桌面端和移动端都要可用；移动端优先保证正文宽度和导航可访问。

## 内容呈现

- 不改写 Markdown 原文来迁就样式；通过 VitePress 配置和 CSS 解决展示问题。
- 文章标题、更新时间、目录和正文保持一致。
- 图片保持原始比例，点击/缩放行为以简单可靠为先。
- 搜索结果应能区分文章标题和摘要。

## 修改约束

- 优先使用 VitePress 内置功能。
- 小范围视觉调整优先修改 `website/.vitepress/theme/custom.css`。
- 只有确实需要复用的交互或复杂布局才新增 Vue 组件。
- 不为了视觉效果引入大型 UI 框架或不必要的依赖。
