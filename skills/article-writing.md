# 文章写作规则
- 使用中文描述，专有名词、模块名和 API 保留英文。
- 先说明背景与核心思想，再解释架构、数据流、关键模块、训练和推理。
- 重要公式说明变量、张量形状和适用条件。
- 区分论文提出的内容、官方代码实现和作者推断；不确定之处明确标注。
- 保留可靠来源链接，避免无依据的结论。

- 行内公式统一使用 `$x$`，公式分隔符与公式内容之间不要留空格。
- 独立成行或多行的公式统一使用 `$$...$$`，不要用单个 `$` 包裹显示公式。
- 多行公式可使用 `aligned`、`cases` 等 LaTeX 环境；检查左右分隔符成对，并确认公式没有被误放进代码围栏。
- 发布前至少检查一条行内公式、一条多行公式和一条较长公式在网页中的显示效果。
